Substitui a `change_list` padrão porque uma categoria não se lê em linha: ela se lê dentro de onde está. Aqui a hierarquia é indentada, os filhos recolhem, e buscar, filtrar, ordenar, ativar, criar e editar acontecem nesta tela. O que a página monta vem do servidor (`CategoryAdmin._changelist_context`): as linhas já filtradas e ordenadas, as colunas com o link da próxima ordem, os idiomas ativos da loja e as permissões. O JavaScript (`admin/js/category_admin.js`) cuida do que é de tela — recolher, selecionar, abrir o modal — e grava sempre pelos endpoints do Admin. Sem JavaScript a lista continua legível e a ficha completa continua acessível pelo link "Editar" de cada linha. {% endcomment %} {% comment %} `media` é o CSS e o JavaScript declarados no `Media` do `CategoryAdmin`.
